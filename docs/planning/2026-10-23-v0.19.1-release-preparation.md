# LSS 0.19.1 release preparation

Prepared 2026-10-23. **0.19.1 ships on the 26.3 line only**: the Paper plugin now runs on Folia
26.3 (experimental; Folia's own 26.3 builds are ALPHA). The [plan](2026-10-23-folia-26.3-plan.md)
records the design, both review folds and the soak evidence. Identities, counts and jar hashes
are in the [manifest](../implementation/2026-10-23-v0.19.1-release-preparation.json).

  `folia`; the mainline `ReleaseWorkflowContractTest` pin flips; stale comments; version 0.19.1;
  notes in `v0.19.1-release-notes/main.md`.

  experimental on 26.3). No version bump, no tag. Never cut a support-line 0.19.1; the next
  support-line patch is 0.19.2.

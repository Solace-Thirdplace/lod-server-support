# LSS 0.18.0 release preparation

Prepared 2026-10-12. The candidates were restaged the same day to add Sponge, at the user's request: "all in one release", and restaged again for the [DH push lighting fix](#dh-push-sky-light-fix) found in testing. **All six pinned candidates pass the exact-version local gate.** Identities, counts and the 48 jar hashes are in the [manifest](../implementation/2026-10-12-v0.18.0-release-preparation.json). The release branches are pushed to PRs #343–#348. **The release is on hold for more testing (user decision 2026-10-12).** Nothing is merged, tagged or published.

0.18.0 is the first release on Minecraft 26.3, which is now `main`. 26.2 continues on `support/mc26.2` and now takes a `+mc26.2` tag suffix.

## What 0.18.0 contains

- **Minecraft 26.3.** This is a new line: Fabric, Paper/Purpur, NeoForge and Sponge. Folia has no 26.3 build. Voxy has published no 26.3 build, so a 26.3 client gets maps and far players but no LOD terrain until it does.
- **Sponge (experimental) on all six lines.** This is the SpongeVanilla server plugin (`sponge/`), ported to 26.3 and shipped with `LINE_SHIP_SPONGE=true`. The [Sponge support plan](2026-10-10-sponge-support-plan.md) records the decisions.
- **JourneyMap map ingestion.** The neutral `integrations.map_ingestion` setting is on for new settings files. JourneyMap's 1.21.10 beta is unsupported.
- **LOD distance 0** switches LOD service off in that dimension or world.
- **The post-0.17 review fixes.** These include the `<dim>.maponly` cache marker: a map-only download no longer seals terrain against a later Voxy install.
- **The DH push lighting fix.** Terrain from Distant Horizons real-time updates no longer turns black just past the vanilla view (a 0.17.0 bug).

## DH push sky-light fix

**Found in testing.** On the 26.3 DH-only rig, LOD chunks just past the vanilla view turned black as the player moved. Voxy's store showed DH-shaped columns with block light but zero sky light; the server's DH database was fully lit.

**Cause.** Official DH 3.3.4 bakes sky light only when it merges an update into its stored tile (`FullDataUpdaterV2`). It sends the real-time push before that, so a push carries zero sky light. A DH client re-bakes on storing it; LSS converted the push as it arrived. Only columns outside the vanilla view are written, which made the dark ring.

**Fix, on all six lines.**

- Pushes are baked with a port of DH's `bakeDataSourceSkyLight` (`DhSkyLightBake`) and DH's block opacity rule.
- A push that writes columns without covering the whole tile schedules one full refetch of the tile two seconds later. A push baked alone lacks light from neighbouring chunks, and the server's merged reply replaces it.
- The sideways spread is capped (16M steps; real tiles use at most 2.04M), so a hostile server cannot stall the client's DH worker.
- `CONVERSION_VERSION` 6 makes every 0.17.x tile download again when the player returns to it, which clears columns already stored black.

**Verification.**

- Wiping and re-baking all 365 tiles from the rig's DH database reproduces DH's stored values exactly (14,973,231 spans, 0 mismatches).
- 262 DH tests pass on every line, including a session-level zero-sky push that fails if the push path stops baking.
- The user confirmed live that the dark ring is gone, on the first version of the fix.
- A 4 Opus + 1 Fable review found no blockers. Its majors (neighbour light, the hostile-tile stall, push-path test coverage) are folded. The [DH design record](../implementation/2026-10-10-dh-remediation.md) has the addendum.

**Jar effect.**

- The Fabric and NeoForge jars change on every line.
- The LSS Paper and Sponge jars are byte-identical to the Sponge candidates.
- The VSS Paper and Sponge jars differ only in zip entry timestamps.

## Known limits

- Voxy has no 26.3 build.
- Folia has no 26.3 build. Folia remains experimental, and is unavailable on 1.21.1 and 1.21.10.
- Sponge is experimental on every line, and four of the six pins are SpongeVanilla RCs.
- NeoForge remains best-effort, with distant-player rendering on 1.21.1 only.
- Far players show base armor and items only.
- The Xaero first-spawn gaps, the 1.21.1 low-view-distance corner seam and the shader/LOD-depth limits remain.
- On DH servers with neither sync nor generation, a push keeps the local bake: near chunk borders it can be slightly darker than a DH client shows.
- Follow-up, not a release blocker: DH conversion's floor-light lookup is quadratic in the spans per column, so a hostile DH server can still make conversion slow. This predates 0.18.0.

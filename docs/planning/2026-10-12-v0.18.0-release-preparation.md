# LSS 0.18.0 release preparation

Prepared 2026-10-12. The candidates were restaged the same day to add Sponge, at the user's request: "all in one release". **All six pinned candidates pass the exact-version local gate.** Identities, counts and the 48 jar hashes are in the [manifest](../implementation/2026-10-12-v0.18.0-release-preparation.json). The release branches are pushed to PRs #343–#348. **The release is on hold for more testing (user decision 2026-10-12).** Nothing is merged, tagged or published.

0.18.0 is the first release on Minecraft 26.3, which is now `main`. 26.2 continues on `support/mc26.2` and now takes a `+mc26.2` tag suffix.

## What 0.18.0 contains

- **Minecraft 26.3.** This is a new line: Fabric, Paper/Purpur, NeoForge and Sponge. Folia has no 26.3 build. Voxy has published no 26.3 build, so a 26.3 client gets maps and far players but no LOD terrain until it does.
- **Sponge (experimental) on all six lines.** This is the SpongeVanilla server plugin (`sponge/`), ported to 26.3 and shipped with `LINE_SHIP_SPONGE=true`. The [Sponge support plan](2026-10-10-sponge-support-plan.md) records the decisions.
- **JourneyMap map ingestion.** The neutral `integrations.map_ingestion` setting is on for new settings files. JourneyMap's 1.21.10 beta is unsupported.
- **LOD distance 0** switches LOD service off in that dimension or world.
- **The post-0.17 review fixes.** These include the `<dim>.maponly` cache marker: a map-only download no longer seals terrain against a later Voxy install.

## Sponge integration

**Merge.** Each support line merged its `release/v0.18.0-mc<line>` candidate into `feat/sponge-mc<line>`. The resolutions:

- The client snapshot moved to `ClientMetricsExporter`, which keeps the new map-ingestion metrics line.
- The settings reference keeps the map-ingestion rename text under the Sponge server title.
- Installation keeps the Sponge paragraph and the MC-upgrade store note.
- The notes combine both feature sets.

**26.3 port.** 26.3 got a three-way port of the 26.2 Sponge delta, plus line facts:

- SpongeVanilla `26.3-21.0.0-RC2745`, the newest RC, with its universal sha1 pinned.
- SpongeAPI `21.0.0-20261005.191039-3`, a timestamped snapshot.
- VanillaGradle 0.3.2.

The three mixin targets are unchanged from 26.2.

**Merge fixes.**

- The client-only map-ingestion classes (`JourneyMap*`, `IngestBackpressureGovernor`, `MapMemoryGuard`) are excluded from the Sponge server jar.
- The Sponge `ScopedCarrier` twin was re-synced to the Fabric copy.
- The boot smoke stages `white-list=false`.

**Ship evidence on every line.**

- `:sponge:build` and the two-phase `:sponge:bootSmoke` on the pinned server: hooks, 13 channels, a disk serve, and the store reading `ok`.
- `SOAK_PLATFORM=sponge` `fresh-backfill` and `dirty-broadcast`: 12/12 pass with 0 violations.

A read-only integration review found no lost or duplicated hunks. Every release-side fix reaches the Sponge paths: `white-list=false`, the URL-stamped downloads, the 26.3 gamerule readback, distance 0 and the YAML config. Not run: the plan's §5.3 native server-smoke rig with Windows clients, and the §5.5 manual floor. They belong to the testing hold.

## Known limits

- Voxy has no 26.3 build.
- Folia has no 26.3 build. Folia remains experimental, and is unavailable on 1.21.1 and 1.21.10.
- Sponge is experimental on every line, and four of the six pins are SpongeVanilla RCs.
- NeoForge remains best-effort, with distant-player rendering on 1.21.1 only.
- Far players show base armor and items only.
- The Xaero first-spawn gaps, the 1.21.1 low-view-distance corner seam and the shader/LOD-depth limits remain.

## Publication handoff (after the testing hold)

- **LSS:** 22 jars through `release.yml`:
  - Fabric, Paper and Sponge on all six lines;
  - NeoForge on 26.3, 26.2, 26.1 and 1.21.1.

  The 1.21.10 and 1.21.11 NeoForge jars are built and checked but not published.
- **VSS:** 24 jars (Paper, NeoForge, Sponge and Fabric on six lines), published locally by `~/.local/state/lss-publish-v0.18.0/publish-vss.py`. The conventions are unchanged: empty changelog, bare version, unversioned filenames, no dependencies, `featured: false`.
  - Rows that existed in 0.17.0 copy its loaders and game versions.
  - The 26.3 rows and the Sponge rows are seeded from `line.env`.
  - 26.3 Fabric is published last.
  - The script refuses to run until the LSS release is verified (`lss-verified.json`).
- **Order:**
  1. Run `:sponge:build --refresh-dependencies` on each line.
  2. Merge #343–#348 with **merge commits only**.
  3. Put annotated `--cleanup=verbatim` tags on the merge commits and push them one at a time. Notes come from `docs/planning/v0.18.0-release-notes/`.
  4. Verify six GitHub releases and 22 LSS Modrinth versions.
  5. Publish VSS.

  Never rerun a partially published release.
- **PR #314** (the original Sponge port): the plan calls for retargeting it to `support/mc1.21.11-v0.14` so that it closes as merged when #346 merges. This needs the user's go.

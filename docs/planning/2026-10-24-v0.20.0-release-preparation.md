# LSS 0.20.0 release preparation

Prepared 2026-10-24 on all six lines. Identities, counts and jar hashes are in the
[manifest](../implementation/2026-10-24-v0.20.0-release-preparation.json). Notes:
`v0.20.0-release-notes/` (one file per line).

## Scope

- **Draw far players farther (#364)**: opt-in `far_players.extend_far_plane`
  ([plan](2026-10-23-far-plane-extension-plan.md) on main, incl. its visual check: on 26.x
  vanilla atmospheric fog still hides far players past about 900 blocks unless the LOD mod's fog is
  off; documented).
- **Paper/Folia version guard + LOD store build marker**
  ([plan](2026-10-23-paper-version-guard-store-plan.md)): a 26.2 jar on Paper 26.3 decoded old
  chunks as air and poisoned the store. Paper now refuses a jar outside `minecraft_dependency`;
  the store records the jar's build; unmarked Paper/Folia stores rebuild once.
- **Per-player map ingestion permission** ([plan](2026-10-23-map-ingestion-permission-plan.md)):
  `lss.map_ingestion`/`vss.map_ingestion` (default false) exempts a player from
  `privacy.request_no_map_ingestion`.
- **Tests**: `RegionSummaryServiceTest` quit-during-assembly races (barrier + RETRY) and the
  `SerializerParityGameTests` deposit wait (wall clock); both in the flake catalog.

Reviews: plans 2 Opus + 1 Fable each; implementation 4 Opus (covering everything since
v0.19.1); every finding folded or dispositioned in the plans.
